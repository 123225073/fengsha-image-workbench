# 海报多对话与成品历史 · 1.2.2

用户场景：同一项目先生成三个尺寸，再继续沟通生成同尺寸的三张图；旧版成品区只展示每个尺寸最新一张。同时，新对话入口位于右侧滚动区域深处，历史对话超过八个会被截去。

修复后：

- 顶部提供“本项目对话”切换框和“新对话”，与“新建项目”分开。各对话保留完整沟通、草稿、设计方案和独立摘要会话编号。
- 成品区根据当前项目完整生成记录累积展示所有仍在素材库的图片，按每个尺寸标记生成次数，最新结果在前；生成中的新图不会替换已交付图片。
- 每个结果绑定自己的图片与任务，下载、编辑、预览和生成状态对应原图。ZIP 导出全部历史成品，文件名包含图片编号，避免同尺寸文件覆盖。
- 新的参数制图任务保存当时的文字和标识素材，后续修改文案不再改变其历史版本。旧任务没有保存的参数快照无法追溯重建；AI 完整出图直接使用原始图片。
- 无数据库迁移，也不复制或删除已有图片；旧项目有完整生成记录的成品直接恢复显示。

验证：

- Python 全量 50 项通过，包括项目保存恢复 11 个历史对话、用户隔离、超过全局 200 条任务列表仍保留当前项目历史、文案快照及标识素材权限。
- 前端回归覆盖两批共六张、刷新重建、隐藏任务后仍保留成品、项目隔离、生成期间保留旧图、独立对话恢复、单图下载和编辑、ZIP 内容与文件名。
- 隔离浏览器环境使用本地模拟图片和回复：实际提交第二批三张，确认六张累积；新建第二对话、切回第一对话、刷新、新建另一项目再重开原项目均保留；编辑第一批图片显示第一批内容。
- 不调用付费生图或语言模型，不改变真实账户余额。
